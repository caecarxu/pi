# 在终端中使用 Pi

> 本文为简体中文译本；[查看英文原文](../usage.md)。

在你想要处理的文件夹中运行 `pi`。Pi 会从该文件夹发现文件、指令和配置，并据此归类保存的会话。如果尚未安装 Pi 或选择模型，请先阅读[快速开始](quickstart.md)。

Pi 在加载项目资源前，可能会询问你是否信任当前工作文件夹。详情见[项目目录信任](security.md#understand-project-trust)。

<p align="center"><img src="../images/interactive-mode.png" alt="Pi 交互模式，显示对话、编辑器和状态信息" width="750"></p>

对话记录会显示你的提示、Pi 的回复、工具调用、结果和错误。你可以在编辑器中输入提示和命令。页脚显示当前文件夹、会话、模型、上下文使用量以及累计用量和费用。

## 输入提示

输入请求并按 `Enter` 发送。按 `Shift+Enter` 换行；输入较长的提示时，按 `Ctrl+G` 可在配置的外部编辑器中编辑。

要附加文件或图片：

- 输入 `@` 搜索文件并添加到提示中。
- 按 `Tab` 补全路径。
- 在兼容的终端中粘贴图片或将图片拖入终端。

## 跟进 Pi 的工作

Pi 会在工作过程中显示每次工具调用及其结果。按 `Ctrl+O` 展开或折叠工具输出；按 `Ctrl+T` 显示或隐藏思考内容。

启动信息会列出 Pi 已加载的指令和资源。编辑器边框表示当前思考级别。页脚会随模型上下文使用量和用量信息更新。

Pi 不会在每次工具调用前征求确认。请检查命令和变更文件；处理不可信任务或无人值守任务时，请使用沙箱。详见[安全指南](security.md)。

## 调整方向

Pi 工作期间，你可以继续输入：

| 目的 | 操作 |
|---|---|
| 调整当前任务 | 输入消息并按 `Enter` |
| 在当前任务结束后追加工作 | 输入消息并按 `Alt+Enter` |
| 将排队的消息退回编辑器 | 按 `Alt+Up` |
| 停止当前任务 | 按 `Escape` |

按 `Enter` 发送的消息会等当前回复和工具调用结束，再引导下一次回复。按 `Alt+Enter` 发送的后续消息会等 Pi 完成当前任务。中止任务时，排队的消息会退回编辑器。

Windows Terminal 会占用某些 Alt 快捷键。Windows 下的替代操作见[终端设置](terminal-setup.md)。

## 更换模型或设置

输入 `/` 搜索可用命令。最常用的命令包括：

- `/model` 选择模型。按 `Ctrl+L` 可打开同一个选择器。
- `/thinking` 选择当前模型的推理强度。按 `Shift+Tab` 可循环切换受支持的级别。
- `/login` 和 `/logout` 管理供应商访问权限。
- `/settings` 修改常用偏好。

提示模板、技能和扩展也可以向同一个菜单添加命令。详见[选择模型](models.md)、[配置](configuration.md)或完整的[斜杠命令参考](slash-commands.md)。

## 继续会话或重新开始

除非禁用了会话持久化，否则 Pi 会自动保存会话。

- `/new` 开始新会话。
- `/resume` 打开另一个已保存的会话。
- `/name` 为当前会话设置一个易识别的名称。
- `/session` 显示会话文件、ID、消息数、令牌用量和费用。

想探索其他方案而不丢失已有工作时，可使用 `/tree`、`/fork` 或 `/clone`。使用 `/compact` 减少发送给模型的对话历史。相关工作流见[会话与上下文](sessions.md)。

退出 Pi 后，在同一文件夹中运行 `pi --continue` 可继续最近的会话。

## 运行终端命令

在命令前加 `!`，即可运行它并将输出加入对话：

```text
!git status
```

使用 `!!` 可运行命令而不把输出发送给模型。

## 复制、导出或分享结果

按 `Ctrl+X` 或运行 `/copy` 复制最近一条助手回复。使用 `/export` 将会话保存为 HTML 或 JSONL。

使用 `/share` 上传会话并获取查看链接。默认情况下，若已通过 Radius 认证，生成的内容会对你的 Radius 组织可见；否则 Pi 会通过 GitHub CLI 创建私有 gist。`sessionShareDestination` 设置可强制选择其中一种目标，见[设置](settings.md#sessions-and-context)。分享前请先检查会话，因为其中可能包含提示、工具输出、文件内容，以及对话期间暴露的凭据。

## 调整终端

默认的全屏模式会固定编辑器和状态栏，并让对话记录在终端窗口内滚动。普通模式使用终端自身的滚动历史。可通过 `/settings` 或 `--tui-mode` 选择模式。

各终端对鼠标输入、快捷键和行内图片的支持有所不同。平台配置见[终端设置](terminal-setup.md)，所有可配置快捷键见[键位绑定](keybindings.md)。运行 `/hotkeys` 可查看当前会话实际启用的快捷键。

## 收集诊断信息

排查终端渲染或对话状态问题时，运行 `/debug`。Pi 会将渲染后的终端行和当前会话消息写入 Agent 目录中的 `pi-debug.log`，详见[配置](configuration.md#agent-directory)。

分享前请检查该文件，其中可能包含提示、模型回复、工具输出、文件内容和终端数据。
