# 会话与上下文

> 本文为简体中文译本；[查看英文原文](../sessions.md)。

Pi 将一次对话保存为会话。会话的活动分支为下一次模型请求提供对话历史。使用会话命令可以继续工作、探索其他分支，或减少发送给模型的历史内容。

## 继续或切换会话

除非使用 `--no-session` 启动 Pi，否则会话会自动保存。

```bash
pi --continue
pi --resume
```

`--continue` 打开当前目录最近的会话。`--resume` 打开会话选择器。交互模式下，`/resume` 会打开同一选择器，`/new` 则开始新会话。

每个会话都会记录其创建时的工作目录，此后不会更改。Pi 会在会话的工作目录中运行，因此工具、`@path` 引用、项目配置和上下文文件都会从该目录解析。

| 入口 | 工作目录 |
|---|---|
| `--continue` | 当前目录 |
| `--resume`、`/resume`、`--session`、`/import` | 会话自己的工作目录，可能与当前目录不同 |
| `--fork`，或选择从其他目录中的会话 ID 创建分支 | 当前目录，新会话 |

如果会话的工作目录已不存在（例如项目文件夹被重命名），交互模式会询问如何打开：

- **Continue**：在当前目录中运行此会话。Pi 不会保存这一选择，下次打开会话时仍会询问。
- **Fork**：将会话复制到当前目录并创建新 ID，效果类似 `--fork`。原会话保持不变。启动时，副本会像当前目录的其他新会话一样保存；通过 `/resume` 或 `/import` 操作时，副本会像 `/new` 一样保存到当前会话旁边。
- **Cancel**：保持当前会话打开；如果是在启动时选择，则退出。

其他模式会直接报错退出。

使用 `/name` 或 `--name` 为会话设置易识别的名称。运行 `/session` 可查看当前会话文件、ID、消息数、令牌用量和费用。

会话选择器可以搜索、重命名和删除会话，也可以显示路径、更改排序方式，并将结果限制为带名称的会话。快捷键见[键位绑定](keybindings.md#sessions)。

## 选择分支方式

Pi 将会话条目保存为树，因此返回较早位置时，不会删除离开的分支。

| 操作 | 结果 | 适用场景 |
|---|---|---|
| `/tree` | 在当前会话文件中切换位置 | 相关方案应放在一起 |
| `/fork` | 从较早的用户消息创建新会话 | 备选方案应成为独立工作 |
| `/clone` | 将活动分支复制到新会话 | 需要将当前状态复制一份单独处理 |

在 `/tree` 中选择一条用户消息，会将其文本放回编辑器。编辑并提交后会创建另一条分支。选择助手回复或其他条目，则从该条目之后继续，编辑器为空。

离开某个分支时，Pi 可以为它生成摘要，并将摘要附到你进入的分支。这样既能保留已放弃路径中的相关工作，又不必把每条消息都纳入上下文。

会话树和条目类型的持久化格式见[会话格式](session-format.md)。

## 管理对话上下文

模型接收的是活动分支，而不是会话文件中的所有分支。Pi 会将该历史与系统提示、发现的上下文文件、可用工具和已加载的技能描述组合起来。[Pi 的工作原理](how-pi-works.md#context)说明了这些输入如何组装。

页脚会显示当前上下文用量。活动上下文接近模型上限时，Pi 通常会自动压缩较早的历史。压缩会加入摘要并保留最近消息，但不会删除原始会话条目。

运行 `/compact` 可手动压缩。你可以补充指令，指定摘要应保留某个主题或决定。自动压缩和保留历史的设置见[设置](settings.md#compaction)。

如果供应商不可用，或无法接受摘要请求，压缩可能失败。修复供应商问题后，再运行 `/compact`。禁用自动压缩不会禁用手动命令。

阈值、保留边界、分支摘要行为和扩展钩子见[压缩参考](compaction.md)。

## 控制会话存储

默认情况下，Pi 将会话按工作目录分组，保存到 `~/.pi/agent/sessions/`。可使用 `--session-dir`、`PI_CODING_AGENT_SESSION_DIR` 或 `sessionDir` 设置指定其他位置。优先级最高的是 CLI 选项。

临时运行时可使用 `--no-session`。临时会话无法在 Pi 退出后恢复。

## 导出或分享会话

使用 `/export` 将当前会话写出为 HTML 或 JSONL。使用 `/share` 上传并获取查看链接。默认情况下，若已配置 Radius 认证，Pi 会创建 Radius 资源；否则会创建私有 GitHub gist。将 `sessionShareDestination` 设为 `gist` 或 `radius` 可强制指定目标。

导出或分享前请先检查会话，其中可能包含提示、模型回复、工具参数、命令输出、文件内容和扩展消息。

## 报告 Bug

运行 `/bug [description]` 为 Pi 开发者准备一份私有报告。你可以附带会话记录、排除会话记录，或让当前模型总结问题。请检查会话记录和生成的摘要，因为它们可能包含敏感对话数据。

报告会包含环境和供应商配置，但不包含凭据值，也会包括记录的错误诊断信息。你可以通过 `radius.pi.dev` 上传，也可以导出同一报告的 zip 文件自行检查和分享。上传不需要登录；通过 Radius 认证后，报告会关联到你的账号，方便开发者跟进。上传失败时，Pi 会提供导出 zip 的选项。
